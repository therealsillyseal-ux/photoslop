Welcome to Photoslop
This is the first functional foundation, not a complete Photoshop or Premiere replacement.
Image studio
Paint on transparent layers, import images, move layers, add editable text and rectangles, select a region, adjust colors, and export PNG. Save a .ffproject to preserve layers. New text layers remain editable: click to type, drag to create a paragraph box, or double-click a T thumbnail to edit again. Ctrl+Enter finishes and Esc cancels. Adjustments are destructive; masks are not available yet.
Video studio
Import videos, add them to a sequential timeline, trim, split, reorder, preview, and export MP4. Preview switches clips but is not frame-accurate or gapless. Media is referenced by its original path, so keep source files in place.
AI setup
See README.md and ai/SETUP.md in the source package. The optional local service provides background removal and selected-clip transcription. No Adobe services or accounts are used.
Shortcuts
Ctrl S: save · Ctrl Z: undo · Ctrl Shift Z: redo
Ctrl J: layer via copy / duplicate · Ctrl Shift N: new layer
Ctrl A / Ctrl D: select all / deselect · Ctrl 0: fit · Ctrl 1: 100%
V / B / E / U / T / M / I / H / Z: image tools
X: swap colors · D: default colors · Tab: tools/options/panels · Shift Tab: right panels · Space + drag: pan
Gray toolbar tools, Channels, and Paths are not implemented yet.
